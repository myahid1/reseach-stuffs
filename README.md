# reseach-stuffs

Group 4 research files for US DOL forced-labour data and HS6 screening.

Start with [Group 4's README](Group%204/README.md) for setup, sources, methodology, and limitations. The folder includes raw downloads, derived CSVs, and the executed [cleaning notebook](Group%204/notebooks/02_dol_data_cleaning.ipynb).

The current output is a first-pass HS2022 screening dataset for analysis year 2025. It includes unresolved mapping gaps and broad candidates requiring review; it has not been merged with the group's SingStat data.

Python virtual environments, caches, and the duplicate Telegram handoff ZIP are excluded from version control.
